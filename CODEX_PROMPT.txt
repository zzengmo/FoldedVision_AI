다른 PC에서 FoldedVision_AI 저장소를 열었어. 이 프로젝트를 이어서 작업해줘.

기준일은 2026-11-26이고 저장소는 https://github.com/zzengmo/FoldedVision_AI.git, 작업 브랜치는 main이야. README.md, AGENTS.md, DATA_SOURCES.md를 읽고 현재 Git 상태와 파일을 확인해줘. 아래 50장 최종 PowerPoint를 기준으로 이어가줘. 이번 목표는 마지막 줄에 적을게. 원본 작업 PC에만 있던 data, archive, 일부 체크포인트가 새 PC에 필요하면 어떤 경로와 자료가 필요한지 알려줘. 자동으로 대용량 데이터를 받거나 전체 학습을 시작하지 말고, 요청한 기능부터 확인해줘.

웹만 수정할 때는 Python, 학습 데이터, 체크포인트가 필요 없어. 노트북 학습·추론 작업이 필요할 때만 Python 3.11 가상환경을 만들어줘. Windows에서 py -3.11 -m venv .venv 실행 후 .venv\Scripts\python.exe -m pip install -r requirements-lock.txt로 설치하고, 노트북 커널을 같은 Python으로 선택해줘. OS가 다르면 호환되는 패키지를 확인해줘.

[최신 웹 상태와 다른 PC 실행]
웹은 sites/foldedvision-inspection/의 React 19.1.0 + Vite 6.4.6 + Three.js 0.180.0 프로젝트야. 이번 작업은 어두운 화면과 반복적인 네모 상자 구성을 흰색·남색·청록색의 밝은 디자인으로 바꾸고, 3D 공정을 자동 시연으로 확장한 거야. 부품 클러스터 이미지, 외주 입고 → 제조 전 외관 검사 → 제조 투입 흐름, 주제 선정 배경, 실제 평가 사진과 지표를 배치했어. 사용자는 전문적이고 풍성한 구성을 원하며 반복되는 카드와 상자·화살표 도식을 싫어해.

새 PC에서 저장소를 clone하거나 기존 작업 폴더에서 git pull --ff-only를 실행하고, Node.js와 npm을 준비해줘. 이번 검증 환경은 Node.js 24.14.1 / npm 11.11.0이었어. Windows PowerShell에서 저장소 루트를 기준으로:
  Set-Location sites/foldedvision-inspection
  npm.cmd ci
  npm.cmd test
  npm.cmd run dev -- --host 127.0.0.1
터미널에 표시되는 Local 주소로 접속해줘. 코드 편집은 dev 서버를 사용해. 최종 빌드는 npm.cmd run build, 빌드 미리보기는 npm.cmd run preview -- --host 127.0.0.1이야. Mac/Linux는 npm.cmd 대신 npm을 사용해. Windows에서 발표 시연만 할 때는 저장소 루트의 Start_FoldedVision.cmd를 더블클릭하면 설치·빌드·브라우저 열기를 진행해. node_modules, dist, .venv는 GitHub에 넣지 않고 새 PC에서 만들어.

3D는 금속 컨베이어, 광학 촬영 카메라와 링 조명, 유리 가드, 조작 패널, 상태등, Lens·Ring·PCB 형상, 분류 갠트리와 세 트레이를 구현했어. 전체/촬영부/분류부 시점이 단계에 따라 전환되고 드래그 회전·스크롤 확대도 돼. 투입 대기 → 이송 → 촬영 → 저장 결과 확인 → 분류 → 복귀를 네 사례에 반복해. 화면 밖과 백그라운드에서는 진행을 멈추며 동작 줄이기 설정에서는 정지 상태로 시작해. 일시정지·재생, 1×/2×, 초기화, 사례 선택, 직접 분류 모드가 있어.

네 시나리오는 PCB 납땜 과다 검출 → 분리, Lens 정상 구역 오검출 → 재검, Ring 오염 유형 오분류 → 재검, PCB2 정상 확인 → 통과야. 저장된 모델 결과와 정답을 이용한 시뮬레이션이지, 새 사진을 실시간 추론하거나 실제 설비를 제어하는 시스템은 아니야. Ring 유형 점수나 Lens 구역 점수를 정상/불량 확률로 바꾸지 말아줘.
