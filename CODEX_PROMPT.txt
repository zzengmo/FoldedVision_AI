다른 PC에서 FoldedVision_AI 저장소를 열었어. 이 프로젝트를 이어서 작업해줘.

README.md, AGENTS.md, DATA_SOURCES.md를 먼저 읽고 현재 Git 상태와 파일을 확인해줘. 이번 목표는 아래 마지막 줄에 적을게. 원본 작업 PC에만 있던 data, archive, 일부 체크포인트가 새 PC에 필요하면 어떤 경로와 자료가 필요한지 먼저 알려줘. 자동으로 대용량 데이터를 받거나 전체 학습을 시작하지 말고, 요청한 기능부터 확인해줘.

가상환경은 새 PC에서 Python 3.11로 다시 만들어줘. Windows에서 py -3.11 -m venv .venv 실행 후 .venv\Scripts\python.exe -m pip install -r requirements-lock.txt로 설치하고, 노트북 커널을 같은 Python으로 선택해줘. OS가 다르면 호환되는 패키지를 확인해줘.

Ring 기준·최종 노트북은 notebooks/ring/에 있어. 이 폴더나 프로젝트 루트에서 실행하면 같은 data, models, outputs를 써. 기존 Ring 모델의 최종 평가는 80.95%(34/42), Macro F1 0.5678이야. 세 가지 결함 유형을 추정하며 정상/불량 판정은 REVIEW로 표시해. Ring과 별개인 베어링 설치 조합 분류는 내부 검증 94.81%, 최종 평가 57.21%(365/638)야. 두 모델의 추론 전처리, 입력 크기, 클래스 순서는 각 설정 JSON과 현재 코드를 따라줘.

렌즈 팀원의 노트북 두 개는 notebooks/lens/에 있어. 저장된 결과를 먼저 읽고, 실행할 때는 notebooks/lens/를 작업 위치로 사용해줘. 렌즈 최종 CNN과 U-Net .keras, 통합 config/metrics/predictions 파일, 테스트 샘플은 팀원에게 받아야 해. 현재 렌즈 CNN은 구역 AP 0.419, Recall 92.1%, 정상 구역 오검출률 65.4%야. 테스트는 불량 사진 52장이라 정상 사진 오검출률은 미측정이고, 위치 U-Net은 실험용이야. 팀 PCB 원본 노트북은 notebooks/pcb/에 있고 기존 재현에 필요한 jahwa 실행 환경은 별도야.

팀 통합이 목표면 받은 모델과 설정을 먼저 검증해줘. Python 추론 API에서 Ring·Lens·PCB를 부품별로 연결하고, React 화면은 검증된 실제 예측·유형·점수·위치만 보여주는 방향으로 진행해줘. 모델을 아직 못 받은 부품은 준비 상태를 명확히 표시하고, 정상/불량 판정이 검증되지 않은 항목은 REVIEW로 표시해줘.

2026-11-23 추가 실험은 outputs/quality_upgrade/REPORT.md를 읽어줘. 노트북 02 마지막 절에서 링 결함 유형, 렌즈 구역, VisA PCB1–3 사진 분류, 별도 MSDD 학습과 추론을 실행할 수 있어. 추가 원본 PC 데이터는 data/external/quality_upgrade/에 있고 가중치는 models/quality_upgrade/에 있어. 기존 팀 PCB4 YOLO 및 Lens U-Net과 별도 실험이야. React 웹은 Start_FoldedVision.cmd에서 실행하고 추가 학습 섹션에서 재학습 지표 및 실제 평가 사례를 볼 수 있어.
