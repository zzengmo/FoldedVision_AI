# FoldedVision AI 검사실

Ring·Lens·PCB의 실제 평가 사례를 살펴보고, 3D 검사 라인에서 투입·촬영·분류를 연습하는 React 포트폴리오입니다.

## 로컬 실행

Windows에서는 프로젝트 루트의 [Start_FoldedVision.cmd](../../Start_FoldedVision.cmd)를 더블클릭합니다. Node.js와 npm이 설치되어 있으면 첫 실행 때 웹 패키지를 준비하고 브라우저를 엽니다. 사용하는 동안 CMD 창을 열어 두고, 종료할 때는 `Ctrl+C`를 누릅니다.

PowerShell로 실행할 때는 프로젝트 루트에서 아래 명령을 사용합니다.

```powershell
Set-Location sites/foldedvision-inspection
npm.cmd ci
npm.cmd run dev -- --host 127.0.0.1
```

터미널의 Local 주소를 엽니다. 빌드 결과를 확인하려면 같은 폴더에서 `npm.cmd run build`와 `npm.cmd run preview -- --host 127.0.0.1`를 실행합니다.

## 화면 구성과 자료

- **3D 공정 체험**의 네 사례는 저장된 평가 사진과 모델 결과를 사용합니다. 검사 시작 후 촬영 화면을 확인하고 통과·재검·분리를 선택하면 분류 장치와 트레이에서 이동을 볼 수 있습니다. 선택 경로, 권장 경로와 정답 근거가 함께 표시됩니다.
- **시점 전환**은 라인 전체, 촬영부, 분류부를 제공합니다. 드래그로 회전하고 스크롤로 확대할 수 있습니다.
- **평가 비교**는 Lens 구역, Ring 유형, PCB1–3 사진의 전후 결과를 실제 사례와 함께 표시합니다. 카드를 선택하면 해당 모델의 세부 근거를 엽니다.
- **검사 사례**는 각 부품의 저장된 평가 기록과 사진입니다. Ring은 분류와 Grad-CAM, Lens는 CNN 구역과 U-Net 마스크, PCB는 YOLO 정답·예측 박스와 PCB4 집계를 표시합니다.
- **성능 비교**에는 부품별 평가 단위와 한계를 기재했습니다. 엔진 베어링 설치 상태는 별도의 추가 실험입니다.
- **추가 학습**에서는 Ring·Lens의 기존 테스트와 재학습 수치, PCB1–3 분류 지표, 각 모델의 실제 정답 및 오류 사례를 확인합니다. 지표는 저장 모델을 재검증해 만든 `src/qualityResults.json`에서 읽습니다.
- **개발 과정**은 데이터 탐색, 전처리, 모델링, 최종 평가의 사진과 그래프를 단계별로 엽니다.

평가 기록의 출처는 화면과 `src/evidence.json`에 있습니다. 정적 증거 이미지는 `public/evidence/`에, 3D 공정은 `src/FactoryScene.jsx`에 있습니다. 이 포트폴리오는 브라우저에서 실제 저장 결과와 가상 체험을 재생합니다. 내 사진 업로드 추론은 이후 팀 모델을 연결하는 작업입니다.
