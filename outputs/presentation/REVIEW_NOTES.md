# FoldedVision AI 공통 발표자료 검토 기록

기존 `FoldedVision_공통발표.pdf`의 공통부 11장을 검토해 연구 질문을 중심으로 새 공통부 10장을 구성했다. 개인별 실험은 후속 발표에 쓰며 기존 파일의 Ring 8장과 Lens·PCB 파일은 보관했다.

## 슬라이드 구성

| 장 | 새 구성 | 기존 자료에서 달라진 점 |
|---|---|---|
| 01 | FoldedVision AI | 실제 세 데이터셋의 검사 이미지와 정식 주제를 배치 |
| 02 | 사전 검사 필요성 | 공개 결함 사진을 공정 개념도에 넣고 검사 누락에서 추가 검사·재작업 가능성까지 연결 |
| 03 | 연구 질문 | 부품 사진, 딥러닝 검사, 후속 유입 분석을 연결하고 Recall·FN·FP를 정의할 위치를 마련 |
| 04 | 자화전자 KDT 선정 배경 | 제품 소개를 광학·기구·회로의 기술적 유사성으로 연결하고 자체 광학 원리도로 설명 |
| 05 | 검사 대상 3종 | 데이터셋 원본 사진에 정답 위치를 표시하고 부품별 영상 단서와 모델 과제 제시 |
| 06 | 데이터와 라벨 | 데이터 출처, 기존 학습 범위, 라벨과 평가 단위를 한 표에 비교 |
| 07 | 통합 아키텍처 | 입력 분기, 부품별 출력, 표준화, 판정 경로, 분석을 연결하고 현재 웹 상태 표시 |
| 08 | 평가 설계 | 학습·검증·테스트의 역할, 분할 누수 점검, 동일 조건 비교, 재사용 테스트 해석을 제시 |
| 09 | 사전 검사 효과 | 동일 초기 집합의 검사 없음과 AI 검사 경로를 비교하고 가상 계산 예시 추가 |
| 10 | 검증 범위 | 공개 데이터·가상 분석의 범위와 현장 미검증 항목을 제시한 뒤 Lens·Ring·PCB로 연결 |

기존 일정과 기술 스택 전용 장의 공간은 문제 정의, 통합 구조, 사전 검사 효과에 사용했다. 표지에 전체 기간을 넣었고, OpenCV는 개발 흐름에서 역할로 표시했다.

## 공정 효과의 계산 범위

- 비교 기준은 동일한 초기 검사 집합이다. 사전 검사 없이 전부 투입하는 경로에서 초기 불량 수는 TP + FN이다. 검사 경로에서 TP는 최종 분리된 실제 불량, FN은 통과한 실제 불량, FP는 분리된 정상이다. REVIEW는 재검 후 경로와 정답이 확정되면 포함하고, 미결은 별도로 기록한다. 전 사례의 경로가 확정되고 후속 공정에서 추가 유입·분리가 없다는 가정에서 감소율은 TP / (TP + FN) × 100이다.
- [저장된 가상 시나리오](../metrics/hypothetical_scenario.json)의 입력은 10,000개, 불량률 2%, 최종 Recall 95%, 정상 오검출률 3%다. 초기 불량 200개 중 190개를 분리하고 10개가 유입된다. 정상 9,800개 중 294개도 잘못 분리된다. 불량 유입 95% 감소는 이 가정으로 계산한 예시다.
- 현장 데이터와 생산 설비는 사용하지 않았다. 자화전자 생산라인 성능, 실제 완제품 불량률 감소, 조립 전후 품질 변화, 실측 재작업 비용을 검증하지 않았다.
