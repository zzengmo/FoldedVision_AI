기준 RGB CNN은 20에포크 학습했고 검증 Macro F1은 0.597입니다. 테스트에서는 42장 중 34장을 맞혔지만 표면 미가공 네 장은 모두 스크래치로 예측했습니다. 오른쪽은 실제로 그랬던 저장 추론 사례입니다. 전체 사진을 축소할 때 특정 영역의 단서가 약해질 가능성이 있다고 판단했습니다. 이 사례와 적은 미가공 학습 표본이 2차에서 부분 특징을 보려 한 출발점입니다.

[10:39–11:10] 26장  Ring 문제 해결과 2차 학습
2차에서는 전체 사진 한 장과 서로 겹치는 네 구역을 정해진 위치에서 뽑아 각각 160 곱하기 160으로 만들었습니다. 학습 표본이 적어 사전학습한 MobileNetV2 특징 추출기를 고정했습니다. 부분 평균은 여러 구역의 공통 신호, 최댓값은 한 구역의 강한 단서를 남기려는 구성입니다. 전체 특징과 합쳐 Dense 48 분류기를 학습하고 소수 유형에는 더 큰 가중치를 줬습니다. 네 후보를 같은 검증 12장에서 비교해 Macro F1 0.833인 구성을 선택했습니다.

[11:10–11:55] 27장  Ring 학습 곡선과 혼동행렬
왼쪽은 고정된 MobileNetV2의 특징으로 학습한 2차 분류기 그래프입니다. 정확도는 학습과 검증을 따로 보고, 아래 손실은 낮을수록 좋습니다. 학습 정확도는 거의 100%까지 올라가지만, 검증 손실은 9에포크 이후 다시 오릅니다. 16에포크까지 실행하되 검증 손실이 가장 낮았던 9에포크의 가중치를 복원했습니다. 네 가지 분류기 후보 중 최종 후보를 고를 때는 검증 Macro F1을 사용했습니다. 오른쪽은 같은 테스트 42장의 비교입니다. 행은 정답, 열은 예측이며 대각선이 맞힌 사진입니다. 1차는 미가공 4장을 모두 스크래치로 예측했고 2차는 4장을 맞혔습니다. 그래도 오염 2장을 미가공으로, 스크래치 1장을 오염으로 혼동합니다. 미가공 표본은 4장입니다.

[11:55–12:20] 28장  Ring 2차 추론과 동일 테스트
기존 테스트 42장에서 정답 수가 34장에서 39장으로 늘었습니다. 정확도는 80.95에서 92.86퍼센트, Macro F1은 0.568에서 0.891입니다. 표면 미가공은 0/4에서 4/4로 바뀌었습니다. 오른쪽은 앞에서 본 같은 사진의 두 추론 결과입니다. 추가 데이터의 독립 성능이 아니라 기존에 확인했던 테스트를 다시 사용한 비교이고 미가공 평가 사례는 네 장입니다.

[12:20–12:45] 29장  Ring 결론과 적용 범위
전체와 부분을 함께 보면서 기존 테스트의 유형 분류가 개선됐습니다. 그래도 오염 두 장은 표면 미가공으로, 스크래치 한 장은 오염으로 틀렸습니다. 오른쪽은 그중 오염 사례입니다. 검증된 정상 제품 사진이 없어서 현 단계에서는 유형 추정과 수동 검토 보조를 설명할 수 있습니다. 다음에는 정상과 미가공을 새 촬영 로트에서 확보하고 제품 단위로 학습과 평가가 섞이지 않게 나눠야 합니다.

12:45–17:40  PCB · 사진 판정과 결함 위치

[12:45–13:10] 30장  PCB 검사 데이터 소개
PCB 담당은 사진의 정상·불량 판정과 결함 위치 검출을 맡았습니다. 기존 모델은 납땜과 조립 결함 9종을 다뤘고, 그 원본 학습 사진 3,836장과 PCB4 학습 사진 120장을 후속 학습에 사용했습니다. PCB4는 정상 100장과 불량 100장으로 나눴고, 테스트는 정상과 불량이 각 20장입니다. 화면의 사진은 서로 다른 두 자료의 실제 예시입니다.

[13:10–13:32] 31장  PCB EDA · 사진과 결함 분포
PCB4 학습은 정상과 불량이 각각 60장입니다. 하지만 불량 60장 안에서 부품 누락 18장, 손상 15장, 이물과 산화 각 12장, 스크래치 3장으로 유형별 표본 차이가 있습니다. 테스트에서도 스크래치는 한 장뿐입니다. 전체 정상·불량이 균형이어도 결함별 성능은 넓게 일반화할 수 없다는 점을 확인했습니다.

[13:32–13:57] 32장  PCB 이미지 전처리

[13:57–14:25] 33장  PCB 딥러닝 모델 구성
PCB는 작은 결함이 어디에 있는지 필요해서 사진 전체 분류기 대신 YOLO26m 검출 구조를 사용했습니다. 입력 이미지에서 특징을 추출하고 결합한 뒤, 검출 헤드는 결함의 클래스와 위치, 점수를 출력합니다. 위치는 정답 박스와 비교해 mAP를 계산하고, 사진 판정은 모든 박스 중 가장 높은 점수를 검증 임계값과 비교합니다. 따라서 사진 NG를 맞혀도 박스 위치까지 맞혔다고 해석하지 않습니다.

[14:25–14:57] 34장  PCB 1차 기준 추론과 문제 확인

[14:57–15:31] 35장  PCB 문제 해결과 2차 학습
