Ring 모델 선정 설명 / 2026-11-27

선정 구성: MobileNetV2 폭 1.0 / 전체 사진
범위: 사전 고정한 160×160·학습 33장·검증 12장·기존 테스트 42장 조건의 비교

발표에서 말할 설명

학습 사진이 33장으로 적어 사전학습 특징을 활용하는 전이학습을 검토했습니다. MobileNet은 경량 구조를 가진 비교 후보로 두었고, 직접 구성한 CNN을 기준으로 ResNet50과 EfficientNetB0도 같은 조건에서 비교했습니다. MobileNet은 폭 0.5와 1.0을 모두 확인했으며 전체 사진과 부분 사진 결합을 구분했습니다. 각 조건을 초기값 세 개로 반복한 뒤 검증 결과를 기준으로 선택했습니다. 이번 조건에서는 MobileNetV2 폭 1.0의 전체 사진 구성이 선정됐고, 사전에 고정한 초기값 42의 테스트 결과는 40/42장, 정확도 95.24%였습니다.

MobileNet 사용 이유를 세 단계로 구분

1. 전이학습을 검토한 이유: 학습 33장으로 새로운 특징 추출기 전체를 학습하는 부담을 줄이고 사전학습 특징을 활용하기 위해서다.
2. MobileNet을 비교 후보로 넣은 이유: CPU 실행을 고려해 경량 구조를 검토하기 위해서다. 작은 데이터에 MobileNet이 무조건 최적이라는 뜻은 아니다.
3. 이번 최종 선정 이유: 검증의 세 유형 평균 F1을 3회 평균했을 때 0.6591로 가장 높았다. 테스트 결과를 보고 모델이나 초기값을 고르지 않았다.

질문: 다른 모델도 실제로 학습했나요?

직접 CNN 3회, 사전학습 모델별 전체/전체+부분 조건의 분류층 24회, 총 27회 학습했다. 전이학습 후보는 특징 추출부를 고정하고 같은 설계의 분류층을 학습했다. ImageNet의 1,000개 분류 출력을 그대로 Ring 정답과 비교한 실험이 아니다. 특징 추출부 미세조정은 수행하지 않았다.

질문: 학습 epoch는 같았나요?

최대 55 epoch, 학습률 0.001, 배치 12, 조기 종료 기준은 동일했다. 검증 손실이 개선되지 않으면 종료하므로 실제 학습 epoch는 다르다. 실행별 실제 epoch와 복원 epoch를 모두 기록했다.

질문: 기존 92.86%와 이번 95.24%는 같은 모델인가요?

별도 실험이다. 기존 92.86%는 MobileNetV2 폭 0.5에서 여러 층의 평균/최대 특징과 전체+부분 사진을 결합한 결과다. 이번 공통 비교는 마지막 층의 평균 특징과 공통 분류층을 사용했고, 선정 구성은 별도 파일로 저장했다. 기존 수치를 새 모델의 점수처럼 옮기지 않는다. 기존 모델·웹·Unity 연결도 변경하지 않았다.

질문: 왜 가장 높았던 초기값을 쓰지 않나요?

대표 초기값 42를 학습 전에 고정했다. 세 번 중 테스트 점수가 높은 실행을 골라 점수를 부풀리지 않았다. 3회 반복 평균과 표준편차도 함께 제시한다. 세 초기값의 앙상블 결과는 아니다.

질문: MobileNet이 모든 상황에서 최고라는 뜻인가요?

이번 데이터 분할·입력 크기·고정 특징 추출 조건에서의 선정이다. 다른 해상도, 증강, 미세조정까지 각 모델의 최적 조건을 모두 탐색한 결과는 아니다. 초기값 반복은 교차검증이나 외부 검증을 대체하지 못한다.

질문: 이 정확도로 정상/불량 차단이나 절감액을 말할 수 있나요?

평가 대상은 오염·스크래치·표면 미가공의 결함 유형 세 가지다. 검증된 정상 사진이 없어 정상/불량 판정 성능이나 현장 차단율을 평가하지 않았다. 실제 추론 상태는 항상 REVIEW다.
